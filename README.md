# Quant Crypto

Python 기반 암호화폐 퀀트 자동매매 프로젝트

수학, 통계, 백테스트를 기반으로 매매 전략을 연구하고, 최종적으로 Binance Paper Trading 및 자동 매매 시스템 구축

## Goals

- 암호화폐 시장 데이터 수집
- 수익률 및 변동성 분석
- 퀀트 매매 전략 구현
- 백테스트 엔진 구축
- 리스크 관리
- Paper Trading
- 실시간 자동매매 시스템 구축

## Tech Stack

- Python
- CCXT
- pandas
- matplotlib
- NumPy
- Binance API
